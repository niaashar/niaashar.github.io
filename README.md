

## Страницы
- `index.html` — главная страница.
- `events.html` — листинг мероприятий (CSS Grid).
- `event.html` — карточка события и блок бронирования со схемой зала.
- `simple.html` — учебный пример из первого занятия.
- `styles/styles.css` — общие стили и подключение шрифтов.
- `fonts/MAK-light.woff`, `fonts/MAK-bold.woff` — предоставленные пользователем материалы курса.
- `images/карта_заведения.svg` — оригинальная схема зала из материалов курса.
- `images/event-*.svg` — учебные иллюстрации для афиш, не оригинальные материалы курса.

## Выполненные пункты задания 1.4
1. **Footer внизу**: `.page` — flex-контейнер на всю высоту экрана; `.main` растягивается через `flex: 1 0 auto`.
2. **Шапка сайта**: `.header__inner`, `.header__list` используют Flexbox.
3. **Листинг**: `events.html`, `.events-list__grid` используют CSS Grid.
4. **Бронирование**: `event.html`, `.event-detail__layout`, `.booking__content`, `.booking__fields` используют CSS Grid. Внутри находится оригинальная схема 11 столов из SVG. Красный цвет не интерпретируется как занятость.

## Замечание преподавателя к заданию 1.3
Фон задаётся внешним секциям (`.hero`, `.events`, `.contacts`), а ограничение ширины и отступы — внутренним контейнерам (`.__inner`). Поэтому фон занимает всю ширину окна.
